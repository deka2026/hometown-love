# 전남광주통합특별시 고향사랑기부제 정보 사이트

27개 시군구(전남권 22 시·군 + 광주권 5 자치구)의 고향사랑기부제 운영현황·기부금 사용·답례품 정보 사이트.

- `index.html` — 클릭형 SVG 지도 + 시군구 목록
- `about.html` — 제도 안내
- `sigungu/<slug>/index.html` — 시군구별 운영현황 (모금액·사용사업·특색)
- `sigungu/<slug>/gifts.html` — 시군구별 답례품 (품목·가격·공급업체·연락처 확인분)
- `build/` — 생성기: `make_data.py`(데이터) → `gen.py`(정적 생성). 데이터 갱신 후 두 스크립트 실행

데이터 출처: 2026.7 기준 언론 보도·지자체 발표 (미확인 항목은 사이트에 표기)
