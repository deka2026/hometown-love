# 고향사랑기부제 사이트 정기 갱신 지시문 (2주 1회)

> 이 문서는 정기 갱신 자동 실행(`claude -p`) 또는 데카 세션에서 "고향사랑 갱신해" 지시 때 그대로 따르는 절차다.
> 이사장님 지시(2026-08-01): "고향사랑기부제 사이트 갱신은 2주 1회로 정기적으로 해."

## 원칙

- **교차확인분만 반영**: 언론 보도·지자체 공식 발표에서 확인된 수치만 넣는다. 미확인은 기존처럼 "미확인" 표기 유지.
- **데이터는 `build/make_data.py` 한 파일에만** 있다. HTML은 직접 수정하지 않는다 (생성물이므로).
- 실패하거나 애매하면 억지로 반영하지 말고 그대로 두고 로그에 남긴다.

## 절차

1. `cd ~/workspace/hometown-love && git pull`
2. **조사** — 27개 시군구(전남 22 + 광주 5) 대상으로 웹 검색:
   - 시군구별 고향사랑기부제 모금액 최신 발표 (예: "○○군 고향사랑기부금 2026")
   - 답례품 신규 지정·변경 소식 (고향사랑e음 공지, 지자체 보도자료)
   - 기금사업(사용사업) 신규 선정·집행 소식
   - 제도 변경(상한액·세액공제 등) → `about.html` 관련 내용은 gen.py 템플릿 확인
3. **반영** — `build/make_data.py`에서 해당 시군구 항목 수정. 수치에는 기준월 표기(예: `'3.1억(2026.7 기준)'`)를 유지·갱신.
4. **재생성** — `cd build && python3 make_data.py && python3 gen.py`
5. **검증** — `git diff --stat`으로 변경 범위 확인, 생성된 HTML 한두 개 열어 깨짐 없는지 확인.
6. **배포** — 변경이 있으면 커밋·푸시 (GitHub Pages 자동 배포):
   ```
   git add -A && git commit -m "정기 갱신 YYYY-MM-DD: <바뀐 시군구·항목 요약>" && git push
   ```
   변경이 없으면 커밋하지 않고 "갱신 사항 없음"으로 종료.
7. 갱신 결과(반영/무변경/보류 항목)를 한 문단으로 요약해 남긴다.

## 2차 보강 (여유 있을 때)

고향사랑e음(ilovegohyang.go.kr)에서 시군구별 답례품 상세(가격·공급업체·연락처)를 보강한다. 사이트 크롤링이 막히면 검색 결과로 대체.
